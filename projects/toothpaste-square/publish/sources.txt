# Sources: toothpaste-square

Facts verified 2026-09-29 via web search (WebSearch). Direct page fetches of colgate.com, snopes.com,
mentalfloss.com and healthline.com were blocked by the network proxy, so those claims are locked from
the search-result excerpts of several independent outlets (marked below), not from full-page reads.

1. The myth: green = natural, blue = natural + medicine, red = natural + chemicals, black = all chemicals. LOCKED
   - Snopes, "Do Color Codes on Toothpaste Tubes Identify Their Ingredients?" (rated false)
     https://www.snopes.com/fact-check/false-tube-stakes/
   - Africa Check https://africacheck.org/fact-checks/meta-programme-fact-checks/colour-coded-blocks-dont-indicate-your-toothpastes
2. The square does not identify the composition; fact checkers rated the claim false; manufacturers/regulators do not use it to classify ingredients. LOCKED
   - Snopes (above); Healthline https://www.healthline.com/health/toothpaste-color-code ;
     Mental Floss https://www.mentalfloss.com/article/630094/what-the-color-codes-on-toothpaste-tubes-mean
   - Colgate, "What is a Toothpaste Color Code" https://www.colgate.com/en-us/oral-health/selecting-dental-products/what-is-a-toothpaste-color-code
3. What it is: an "eye mark" (color mark), a printed mark read by a light-beam sensor to locate where packaging is printed, cut, folded or sealed as it moves through machinery. LOCKED
   - Snopes, Colgate, Mental Floss (above); Misbar https://www.misbar.com/amp/en/factcheck/2022/01/22/toothpaste-color-codes-are-for-manufacturing-purposes-only
4. The color only needs to contrast with the tube so the sensor detects it; the same product can carry different mark colors. LOCKED (Snopes: different colors signify different packaging/sensors; Healthline/Ranvoo excerpts on contrast)
   - https://www.healthline.com/health/toothpaste-color-code ; https://ranvoo.com/blogs/oral-health/what-is-a-toothpaste-color-code
5. For actual ingredients, read the ingredient information printed on the tube or box. LOCKED (search excerpt of Snopes/Healthline)

Not claimed in the video: any year, any brand, any regulator statement beyond "toothpaste companies say the same" (Colgate page).
