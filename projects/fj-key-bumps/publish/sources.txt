Sources — fj-key-bumps (fact-checked 2026-09-26)

1. Mental Floss, "The Reason for the Bumps on the F and J Keys" — confirms tactile home-row markers for touch typing.
   https://www.mentalfloss.com/article/623391/reason-for-bumps-on-computer-keys
2. BGR, "Why keyboard F and J keys have bumps" — corroborating explainer, same claim.
   https://www.bgr.com/2113249/why-keyboard-f-and-j-keys-have-bumps/
3. MakeUseOf, "Why Do Keyboards Have a Bump on the F and J Keys?" — corroborating.
   https://www.makeuseof.com/why-keyboards-have-bump-f-j-keys/
4. Type Faster, numpad touch-typing guide — confirms numpad 5 carries a raised dot marking the numpad's
   home position (sources disagree on which finger rests there, so the script does not specify one).
   https://type-faster.com/blogs/numpad/numpad-finger-placement-and-home-keys
5. No solid, citable inventor or start date exists for the F/J bump convention — multiple independent
   explainers state this is unknown. A patent commonly misattributed online as "the F/J bump patent"
   (US 6,667,697 B2, June E. Botich, granted 2003) was checked directly on Google Patents: it covers
   tactile edges on the A key and the semicolon key, NOT F and J. The script references this real
   patent only to say it covers "two completely different keys" — it does not name Botich or claim she
   invented the F/J bump, since that would repeat the misattribution.
   https://patents.google.com/patent/US6667697B2/en
6. Not used / deliberately cut after fact-check: a specific decade for when the F/J bump began (no
   reliable source found); ISO/IEC 9995 and ANSI's 1988 keyboard-layout standard as "the standard that
   specifies the bump" (both are real standards, but neither's actual text could be verified to cover
   the tactile-bump feature specifically — see ANSI Blog https://blog.ansi.org/ansi/standardization-of-keyboard-layouts/
   and ISO https://www.iso.org/standard/51645.html, both about layout geometry, not tactile markers).
