# Background music

Royalty-free instrumentals generated with ElevenLabs Music (paid API account) on 2 Oct 2026 for this channel's
slideshow videos. No vocals, 60 s each, safe to loop. `slideshow.mjs` rotates through them by carousel number
and plays them quietly (about -30 LUFS).

| File | Style |
|---|---|
| 01-lofi-chill.mp3 | lo-fi hip hop, electric piano, soft drums, 85 bpm |
| 02-bright-pop.mp3 | light upbeat pop, plucky synth, claps, 105 bpm |
| 03-chill-house.mp3 | soft chill house, warm chords, 112 bpm |
| 04-indie-acoustic.mp3 | fingerpicked guitar, light percussion, 95 bpm |

Never add a commercial or "trending" song here: uploading one inside the file is a copyright problem and the
platforms can mute or remove the post. To add a new track, generate an instrumental the same way
(`POST https://api.elevenlabs.io/v1/music`, prompt + `music_length_ms`) and note it in this table.
