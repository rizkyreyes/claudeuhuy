# Thumbnails

One file per video: `<posting day in US Eastern time>-<slug>.jpg`, 1080x1920.

The daily run adds the thumbnail when it produces the video. Rizky downloads it here and sets it by hand after the video is live (Instagram: edit the Reel, change cover; TikTok: edit cover; YouTube: custom Shorts thumbnails are desktop-only and may not be open to every channel yet).

Files in this folder are never deleted by the run.
